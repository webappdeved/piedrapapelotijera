# Funcionalidad 2: Permitir al usuario elegir entre jugar contra la computadora o contra otro jugador

## Descripción
Esta funcionalidad permite al usuario elegir si quiere jugar contra la computadora o contra otro jugador.

## Cómo Ejecutar
1. Asegúrate de tener el archivo `funcionalidad2_elegir_oponente.c` en el mismo directorio que el archivo base del juego.
2. Compila el código fuente con el siguiente comando:
   ```bash
   gcc -o piedra_papel_tijera piedra_papel_tijera.c funcionalidad2_elegir_oponente.c
