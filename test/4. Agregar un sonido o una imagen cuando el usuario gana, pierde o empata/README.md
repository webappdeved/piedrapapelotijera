# Funcionalidad 4: Agregar un sonido o una imagen cuando el usuario gana, pierde o empata

## Descripción
Esta funcionalidad agrega un sonido o una imagen para indicar cuando el usuario gana, pierde o empata.

## Cómo Ejecutar
1. Asegúrate de tener el archivo `funcionalidad4_sonidos_imagenes.c` en el mismo directorio que el archivo base del juego.
2. Asegúrate de que los archivos de sonido o imágenes estén en el directorio adecuado.
3. Compila el código fuente con el siguiente comando:
   ```bash
   gcc -o piedra_papel_tijera piedra_papel_tijera.c funcionalidad4_sonidos_imagenes.c
