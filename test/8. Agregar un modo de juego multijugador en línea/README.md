# Funcionalidad 8: Agregar un modo de juego multijugador en línea

## Descripción
Esta funcionalidad agrega un modo de juego en línea para que los jugadores puedan enfrentarse a otros jugadores a través de la red.

## Cómo Ejecutar
1. Asegúrate de tener el archivo `funcionalidad8_multijugador_online.c` en el mismo directorio que el archivo base del juego.
2. Compila el código fuente con el siguiente comando:
   ```bash
   gcc -o piedra_papel_tijera piedra_papel_tijera.c funcionalidad8_multijugador_online.c
