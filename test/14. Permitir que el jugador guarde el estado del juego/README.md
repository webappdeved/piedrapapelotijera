# Funcionalidad 14: Permitir que el jugador guarde el estado del juego

## Descripción
Esta funcionalidad permite al jugador guardar el estado actual del juego y reanudarlo más tarde.

## Cómo Ejecutar
1. Asegúrate de tener el archivo `guardar_cargar_partida.c` en el mismo directorio que el archivo base del juego.
2. Compila el código fuente con el siguiente comando:
   ```bash
   gcc -o piedra_papel_tijera piedra_papel_tijera.c guardar_cargar_partida.c
