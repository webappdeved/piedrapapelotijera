# Funcionalidad 10: Agregar un modo de juego de supervivencia

## Descripción
Esta funcionalidad agrega un modo de juego en el que el usuario debe sobrevivir el mayor tiempo posible contra la computadora.

## Cómo Ejecutar
1. Asegúrate de tener el archivo `funcionalidad10_modo_supervivencia.c` en el mismo directorio que el archivo base del juego.
