# Funcionalidad 13: Permitir que el jugador elija entre diferentes niveles de dificultad (fácil, medio, difícil)

## Descripción
Esta funcionalidad permite al jugador seleccionar el nivel de dificultad del juego (fácil, medio, difícil).

## Cómo Ejecutar
1. Asegúrate de tener el archivo `dificultad_variable.c` en el mismo directorio que el archivo base del juego.
2. Compila el código fuente con el siguiente comando:
   ```bash
   gcc -o piedra_papel_tijera piedra_papel_tijera.c dificultad_variable.c
