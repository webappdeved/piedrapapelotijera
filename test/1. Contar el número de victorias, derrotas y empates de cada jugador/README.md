# Funcionalidad 1: Contar el número de victorias, derrotas y empates de cada jugador

## Descripción
Esta funcionalidad implementa un sistema para llevar el registro de victorias, derrotas y empates para cada jugador.

## Cómo Ejecutar
1. Asegúrate de tener el archivo `funcionalidad1_contar_resultados.c` en el mismo directorio que el archivo base del juego.
2. Compila el código fuente con el siguiente comando:
   ```bash
   gcc -o piedra_papel_tijera piedra_papel_tijera.c funcionalidad1_contar_resultados.c
